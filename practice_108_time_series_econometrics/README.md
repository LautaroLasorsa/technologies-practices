# Practice 108 — Time Series Econometrics: ARIMA, VAR & Cointegration

Two independent random walks regressed on each other to see spurious regression firsthand, then the ADF/KPSS unit-root pair, Box-Jenkins ARIMA identification via ACF/PACF with a conditional-least-squares AR fit, a bivariate VAR with Granger causality and impulse responses, and the Engle-Granger two-step cointegration test with its error-correction model — every estimator validated against `statsmodels`. See [`CLAUDE.md`](./CLAUDE.md) for full instructions, theoretical context, and the command table.
