# Practice 107 — Sensitivity Analysis & Partial Identification

Rosenbaum bounds on a matched design, Oster's delta / R-max, E-values, and Manski / Lee partial-identification bounds — four ways to quantify *identification* error (is the causal assumption even approximately right?) on top of a point estimate's *sampling* error.
