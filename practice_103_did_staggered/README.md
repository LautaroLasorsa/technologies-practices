# Practice 103 — Difference-in-Differences & the Staggered Adoption Problem

The canonical 2x2 DiD and event-study specification, then a staggered-adoption panel with known heterogeneous effects that makes naive two-way fixed effects return an estimate outside the range of every true effect — decomposed (Goodman-Bacon) and repaired by hand-rolling the Callaway-Sant'Anna group-time ATT(g,t) estimator, cross-checked against the `differences` package. See [`CLAUDE.md`](./CLAUDE.md) for full instructions, theoretical context, and the command table.
