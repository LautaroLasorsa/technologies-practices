# Practice 100 — Matching & Propensity Scores

Propensity scores, nearest-neighbor/caliper matching, IPW, and AIPW built from scratch, applied to a real replication of LaLonde (1986): the randomized NSW experiment gives a known ATE, and the CPS-1 observational comparison group badly fails to recover it — this practice shows how much each adjustment method closes that gap, and how much it doesn't. See [`CLAUDE.md`](./CLAUDE.md) for full instructions, theoretical context, and the command table.
