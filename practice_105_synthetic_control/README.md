# Practice 105 — Synthetic Control & Synthetic DiD

A synthetic California built as a simplex-weighted combination of 38 other US states, matched on its pre-1989 cigarette-sales trajectory, to estimate the effect of Proposition 99. Covers donor-pool selection, simplex-constrained weight optimization (a QP), placebo/permutation inference, and synthetic DiD as the reconciliation with the DiD tradition. See [`CLAUDE.md`](./CLAUDE.md) for full instructions, theoretical context, and the command table.
